# Practicals A1 and A2

## A1: Student Records API (Node.js + Express)
```
cd a1-student-api
npm install
npm start        # http://localhost:3000
```

## A2: Feedback Form (React + Vite)
```
cd a2-feedback-form
npm install
npm run dev      # http://localhost:5173
```
The component is `src/FeedbackForm.jsx` (default export).
